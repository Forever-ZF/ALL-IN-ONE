## 零、一页看完

### 结论速览

| 项 | 结论 |
|---|---|
| **最优路径** | **C：先接单 → 再产品化**（垂直 B 端系统 + 托管代运营），而不是先做 SaaS |
| **90 天现实里程碑** | 8 个付费客户，月收入 0–3000 元 |
| **90 天不现实的目标** | 月入过万（这是 3 年期的 P30 事件，不是 90 天的） |
| **5000 元的真实用途** | 买一个「能被验证的最小闭环」，不是买基础设施 |
| **绝对不投** | 付费广告 / 囤货 / 大包外包 / 30+ AI 订阅 / 买课 |
| **最大风险** | 不是技术，是**获客**（60% 的国内 OPC 把获客与销售列为最大困难） |

### 你的三个优势，三个短板

**优势**

1. 程序员 → 开发成本几乎为零。Starter Story 里对标你的案例 dashp，0 员工、**月成本仅 $43**（域名 $12 + Google Workspace $6 + Supabase $25），原型用 Retool 免费额度做。
2. 行业经验可变现。148 份问卷里，**65% 的 OPC 创业者有互联网/科技行业从业背景**——你天然满足「窄而深」的选品前提。
3. 副业形态止损成本低。36 氪调研里「准备直接全职创业的比例为 0」，**已经全职投入的占 95%，尚未抵达可持续全职经营的有 75%**。你不用辞职就已经赢过大多数下了全职赌注的人。

**短板（必须提前设计对策）**

1. **你大概率没有待售的垂直行业关系** —— 这是路径 B/C 的命门，第 1–30 天的核心任务就是补它。
2. **5000 元不能投流** —— Starter Story 头两个案例的获客手段（Google Ads / SEO / HN / 冷邮件）在大陆大半失效。
3. **AI 成本是刚性支出** —— **65% 的 OPC 每月 AI 支出 >500 元，10% >1 万元**，即使当月零收入也要付。你的预算表里必须单列这笔钱。

## 一、先校准期望值：三组数据交叉

在讨论做什么之前，先把「90 天能到什么水平」这件事用数据钉死。这决定了后面所有决策。

### 数据 A：真实流水，不是问卷（最硬的一组）

**Stringers 独立产品收入指数**：11,637 个把 Stripe、RevenueCat、Polar 等支付平台**只读密钥**交出来、收入由支付平台直接计算的产品。数据截至 2026-11-14，每日重算。

| 指标 | 数字 |
|---|---|
| 过去 30 天有任何收入 | **47.0%**（超过一半一分钱没收到） |
| 月收入 ≥ $1,000 | 11.7% |
| 月收入 ≥ $10,000 | 2.9% |
| 月收入 ≥ $100,000 | 0.33%（38 个） |
| 有收入产品的中位数 | **$174** |
| 前 10% 分位 | $4,678 |
| 成立 ≤ 1 年的产品过 $1,000 比例 | **7.4%** |
| 成立 > 1 年的产品过 $1,000 比例 | 19.1% |
| 收入最高的 1% 拿走 | 全部收入的 **56.3%** |
| B2B 过 $1,000 比例 / 有收入中位 | 15.7% / $216 |
| B2C 过 $1,000 比例 / 有收入中位 | 11.6% / $127 |

> **对你（0–1 年）的直接换算：你的产品有 7.4% 的概率做到 $1,000/月，中位数 $110/月。** $1,000 ≈ 7200 元人民币。
> 另一个数字值得单独记：做到 $1,000 之后**并不稳**——2026-04 月收入过 $1,000 的 1,221 个产品，到 2026-10 仍在 $1,000 以上的只有 72.7%，**12.1% 已经跌到 $100 以下**。

### 数据 B：国内样本（148 份有效问卷 + 1500 份问卷）

**《中国企业家》2026-08 专项问卷，148 份有效**（对象是 AI 原生 OPC 创业者/投资人/意向入局者）：

- 40% 已做出产品或服务，**却还没有付费客户**；获得首批付费客户 25%；进入可持续经营 25%
- 愿意披露月收入的样本：**24% 收入为 0，35% 不足 1 万元，41% 在 1 万–10 万元**
- **获客与销售是 60% 受访者最大的困难**；40% 同时受困于交付与客户支持
- **65% 的订单来自老客户或熟人圈层转介绍**，50% 的订单类型是一次性项目/定制
- 每月 AI 支出 >500 元的占 65%，>1 万元的占 10%
- 50% 是「仅本人，无稳定协作者」

**《2026 年中国一人公司（OPC）调研报告》（复旦大学新闻学院，2026-07，1500 份问卷 + 100 小时深度访谈）**：

- 52.4% 处于产品验证阶段，月收入 < 1000 美元（不到 7000 元）
- 37.1% 进入可持续运营区间
- 10.5% 月收入超 10 万美元

### 数据 C：3 年纵向追踪（最有说服力的一份）

**OPC 成长社区追踪 127 位 2023 年入局的 OPC 创业者，到 2026-08**：

- **41 人仍活跃且月入过万（32.3%）**，86 人退出或半死不活
- 幸存者的 4 个共性：**窄而深赛道、AI 工作流化、第一天收费、借势政策**
- 退出者的 5 个坑：没有公司化、盲目囤 AI 工具、追求完美产品、不舍得外包、脱离社群
- **幸存者 41 人里，月入超 5 万的只有 9 人，超 10 万的只有 3 人**

### 三组数据交叉后的结论

> **「90 天做到月入过万」在你的条件下是一个 P10 以下的事件，不是合理目标。**

你的合理目标是阶梯式的：

| 周期 | 合理目标 | 依据 |
|---|---|---|
| **90 天** | **8 个付费客户，月收入 0–3000 元** | 148 问卷：40% 已出产品无付费客户；411 案例：多数停在「注册/激活」层 |
| 12 个月 | 月收入 3000–10000 元 | Stringers：成立 >1 年过 $1,000 比例 19.1%，有收入中位 $174–$378 |
| 36 个月 | 才谈「月入过万」 | 127 人追踪：3 年做到的有 41 人（32%） |

## 二、对 5000 元预算最关键的五条硬约束

这五条，每一条都足以单独否掉一个方案。它们是这个项目真正的难度所在——不是「能不能写出来」。

### 约束 1：个人主体做不了「经营性网站」，B 端的钱从个人卡走不通

- 《互联网信息服务管理办法》第四条：**对经营性互联网信息服务实行许可制度，对非经营性实行备案制度**；第七条：经营性需办理增值电信业务经营许可证。
- 阿里云 / 华为云备案 FAQ 明确：个人备案的网站**「只能展示个人相关的信息」**；涉及经营性业务需另办 ICP 许可证。
- **自然人不能直接以个人名义申请经营性 ICP 许可证**——需先设立公司或个体工商户作为申请主体。
- 微信支付商户进件文档的主体类型里，**小微通道（无营业执照）明确「暂不支持通过此渠道签约线上虚拟行业」**；线上产品基本必须走个体工商户 / 企业主体，资料要求为营业执照 + 经营者证件 + 结算银行账户。
- 36 氪调研里的一句关键观察：OPC **「普遍缺少品牌与资质的背书，招投标场景中常被排除在外」**。

> **对你的影响（决定性）**：B 端客户要合同、要发票、要营业执照。如果主体不对，你连第一单的报价都发不出去。
> **对策：第 0 天先办个体工商户。** 这是你 5000 元预算里第一笔、也是最不可省的一笔钱。

### 约束 2：个体户几乎零成本，5000 元/月收入量级下税务成本约等于零

| 事项 | 金额 / 费率 | 依据 |
|---|---|---|
| 个体工商户注册 | 0–100 元 | 网上全程办免费；刻章最低约 100 元 |
| 增值税 | **月销售额 ≤ 10 万，免征** | 起征点标准，2026-01-01 至 2027-12-31 |
| 个体工商户经营所得个税 | 年应纳税所得额 ≤ 200 万部分**减半** | 2023-01-01 至 2027-12-31 |
| 六税两费 | 减半征收 | 至 2027-12-31 |
| 微信支付费率 | 个体户 **0.6%**，T+1 入账 | 微信支付商户文档 |
| 小程序虚拟支付 | iOS 17%（Apple 12% + 微信 5%）、Android/鸿蒙/Windows 10%；**2026 限时激励：iOS 12%、Android 1%** | 微信虚拟支付技术服务费 |
| 小程序认证费 | 300 元/次 | 腾讯云开发者社区 |
| 微信支付接入申请费 | 0 | 微信支付商户平台 |

> **结论：在 5000 元/月的收入量级，税和支付手续费几乎不构成约束。真正的约束是获客——这与 148 份问卷里「60% 最大困难是获客与销售」完全吻合。**

### 约束 3：如果做 AI 功能，面向公众就要备案 —— 这是隐形工期杀手

《生成式人工智能服务管理暂行办法》第十七条 + 网信办实践口径（各省登记规则）：

| 你的产品形态 | 算法备案 | 大模型备案 | 大模型登记 |
|---|---|---|---|
| 纯调第三方已备案模型 API，面向不特定公众 | 需要 | 不需要 | **需要（省级，3–5 个月）** |
| 同上 + 自有知识库检索增强（RAG） | 需要 | 不需要 | 需要 |
| 同上 + 多步工具调用（智能体形态） | 需要 | 不需要 | 需要（应用层责任更重） |
| 对开源模型做实质性微调后对外服务 | 需要 | **需要** | 不需要 |
| **只服务签约企业客户、不开放注册** | 个案判断，通常不需要 | 通常不需要 | 通常不需要 |
| **只给内部员工用的封闭小程序** | 通常不需要 | 不需要 | 不需要 |

> **策略含义（5000 元预算下最值钱的一条）：优先做「封闭 B 端」——签约客户制、不开自助注册，可以避开算法备案 + 大模型登记，省下 2–8 个月工期和一笔专业咨询费。**
> 反过来说：如果你做的是「面向所有人的 AI 小工具」，2026 年的合规工期会直接推翻你的 90 天计划。

### 约束 4：欧美获客打法在你这里大半失效

Starter Story 里最值得参考的两个案例，其获客手段在大陆的可用性：

| 欧美打法 | 在 Starter Story 案例里的实际表现 | 在大陆的现实 |
|---|---|---|
| Google Ads | bankstatementconverter 前 6 个月每月 $1000，同期月收入 $0 / $101 / $159 / $306 / $233 / $263，**9 月关停** | 不可用 / 无效 |
| Google SEO | BSC 靠「支持更多银行」持续被搜到（4 年做到 $40K/mo） | 中文搜索生态另成一套（微信搜一搜 / 百度） |
| Hacker News | BSC 上首页 → **0 额外付费用户** | 不可访问 |
| Reddit | — | 不可访问 |
| 冷邮件 | BSC 发给 1000+ 会计师事务所 → **只有 1 人付费**，且 GSuite 因高频发送被封 | 不可用 |
| **线下拜访 + 转介绍** | dashp 唯一可行的获客方式（ICP 只有几百家） | ✅ 同样可行 |
| **口碑** | BSC 收入主要来源（稳定但无爆发） | ✅ 同样可行 |

**Stringers 的 11,637 个产品数据（创始人自填获客渠道）也印证了这点**：

| 获客渠道 | 过 $1,000 的比例 | 有收入者中位数 |
|---|---|---|
| 邮件营销 | 23.3% | $590 |
| **口碑** | **24.2%** | **$400** |
| 论坛 | 21.6% | $350 |
| 冷私信 | 14.4% | $313 |
| SEO | 13.0% | $200 |
| Reddit | 9.5% | $155 |
| Product Hunt | 8.6% | $102 |
| Hacker News | 5.2% | $110 |

> **口碑 + 论坛 + 邮件营销 + 冷私信，替代 SEO + Reddit + Product Hunt + Hacker News。** 这四个替代品过 $1,000 的比例都在 21–24%，**是 Reddit/PH/HN 的 2–3 倍**。这就是「欧美打法在中国失效」的量化版本。

### 约束 5：5000 元绝不能投流，投流是净亏损

- **BSC 的 Google Ads**：前 6 个月每月 $1000，同期月收入最高只有 $306 —— **花了远超收入的钱**。
- **Frederick James 案例**（Starter Story 最新头条「$10K/Month 教程」）：第三方核查出其习惯追踪 App 同期的 TikTok 投流约 **$1,000/天（约 $30K/月）**，且未披露净利润。
- **PixelPanda 案例**：Google 广告每周 $35，只换来 1 单。
- **春节小程序复盘**：投入 263 元 → 392 个用户 → 收入约 120 元。

> **你的 5000 元如果投流，会在两周内烧掉，并且让你误判成「这个需求不成立」——而实际是获客方式错了。这是新手最常见的自杀方式，也是本报告里最需要你记住的一条。**

**绝对不投清单**（这四条对应 86 个退出者里的常见死法）：

1. **付费广告 / 竞价 / 买流**
2. **30+ AI 工具订阅** —— OPC 复盘里最夸张的一个人订阅 30+ 款、月费近 1 万元，产出反而很低；活下来的人只用 2–3 款
3. **大包外包**（设计 / 开发）。该外包的只有记账报税，几百块
4. **囤货、买课、买「独立开发教程」**

### 3.2 一个关键决策：境内服务器 vs 境外服务器

| | 境内（阿里云 / 腾讯云国内地域） | 境外（阿里云香港 / 新加坡） |
|---|---|---|
| 价格 | 轻量 2核2G 38–68 元/年 | 香港 2核1G **24 元/月**；海外轻量基础版 25 元/月起 |
| ICP 备案 | 需要，且个人备案不能做经营性 | **不需要** |
| 延迟 | 低 | 香港尚可，新加坡更低 |
| 能否收款 | 能，但需备案 + 个体户 | 能，但国内访问稳定性差 |

> **建议：前 3 个月用境外香港节点（免备案、不用排队等审核），一旦验证出 8 个付费客户，再花约 20 天做境内备案 + 迁移。别在验证之前排队等备案。**

### 3.3 一条容易被忽略的成本：AI 支出是刚性的

36 氪 148 份问卷：**65% 的 OPC 每月 AI 支出超过 500 元，10% 超过 1 万元**，且「即便当月没有订单，工具费用仍需要支付」。

> 所以你的预算表里 AI 必须单列、且必须设上限。对策：**只用 1–2 款国产模型 + 1 款编程助手**，每月底看账单，超过 150 元立刻砍。

## 四、选品：五条硬筛选 + 四个收费信号

### 4.1 五条硬筛选（从两个 Starter Story 案例 + 411 个国内案例反推）

1. **有人每月重复做的枯燥任务。** BSC 案例的结论句：选品 = 选一个「有人每月都会搜索的枯燥任务」。留存也来自这里——会计师全年都要处理 PDF。
2. **行业极度垂直，大厂看不上、小团队没耐心。** 127 人追踪里幸存者的第一共性就是「窄而深」：「宽度输给大厂，深度赢过大厂」。
3. **现有方案是 Excel / 微信群 / 手工。** dashp 的原方案就是 Excel + 邮件。这也证明预算真实存在。
4. **决策人明确且可触达。** dashp 的 ICP 只有几百家，所以只能线下拜访 + 转介绍，不适合跑效果营销也不适合打名单。
5. **必须能覆盖「格式 / 来源」变体。** 这是 BSC 真正的护城河：2022 年为一家 fintech 公司配置所有对账单格式后，「用户订阅概率大幅上升」——**转换不准，用户就不会订阅**。护城河和转化率开关，是同一件事。

### 4.2 四个收费信号（比「大家觉得不错」可靠得多）

来自 411 个一人公司案例的付费断层分析：用户分层五阶段 —— **浏览 → 注册 → 激活 → 付款 → 续费**，多数项目停在第二层。

| 信号 | 含义 |
|---|---|
| 主动询问 | 有人主动来问「能不能帮我做这个」 |
| 需求重复 | 同一个人 / 同一类人反复需要 |
| 已有替代方案 | 现在是 Excel + 人工——**已经有替代方案，才说明有预算** |
| 结果可定义 | 能说清「付这笔钱我完成了什么」 |

> **出现 ≥2 项，可以开始收小额费用试水；≥3 项，才值得正式设计产品和交付。**

### 4.3 候选品类排名（按「程序员 + 5000 元 + 在大陆」的可实施性）

| # | 品类 | 为什么可实现 | 缺点 |
|---|---|---|---|

| **7** | **教培 / 家政 / 维修的微信生态小工具**（排班、派单、评价、对账） | 微信是唯一刚需入口；线下可触达；需求高频 | 客单价被压得很低；行业现金流差、账期长；容易被做成通用工具后失去差异化 |
| **8** | **检测 / 认证 / 证书类文档的到期与校验工具** | 强复购（周期性任务），订阅逻辑天然成立 | 需与行业机构建立信任，周期长；可能触及资质红线 |

### 4.4 三条路径对比

| | A. 中文窄工具 SaaS | B. 垂直 B 端 + 托管代运营 | **C. 先 B 后 A（推荐）** |
|---|---|---|---|
| 顺序 | 做产品 → 找用户 | 找用户 → 做产品 | **接定制单 → 抽出共用内核 → 上订阅** |
| 90 天里程碑 | 上线 + 拿到第 1 个付费用户 | 5–8 个付费客户 | **8 个付费客户，其中 ≥3 个愿意为「标准化版」付费** |
| 行业关系要求 | 不太需要 | **强需求** | 中等，靠转介绍启动 |
| AI 备案 | 面向公众 = 需要（3–5 个月） | 签约客户制 = 通常不需要 | 闭门服务起，后期再评估 |
| 主要风险 | 做成完美产品，6 个月还没上线（退出者第 3 大坑） | 时间被定制吃掉，无法标准化 | 每一步都有现金，风险可分段 |
| 收入形态 | 订阅 | 项目费 + 订阅 | 混合 |

> **推荐 C。** 依据：127 人追踪里「第一天收费」是幸存者的第三共性，「追求完美产品再上线」是退出者的第三大坑。C 让你在第 8 天就有可能收到第一笔钱，而 A 让你在第 60 天还在赌。

## 五、90 天执行计划

### 第 1–30 天：选赛道 + 拿到第 1 笔收入（目标：8 个付费客户）

**第 1–7 天：选 1 个行业，访谈 15–20 个从业者**（不是 20 个朋友，是 20 个目标行业的人）。问 4 个问题：

1. 这个任务你现在多久做一次？
2. 现在用什么做？（Excel？微信群？手工？）
3. 一个月为这件事花多少钱、多少时间？
4. 如果有人帮你做，多少钱你会买？

**第 8–12 天：数「格式变体」** —— 把你这个行业里这类单据 / 表格的格式数一遍。

> **如果少于 8 种，护城河建不起来，换行业。** 这是最便宜、最快的 go/no-go 检查，比写代码早一个月。

**第 13–20 天：做「能跑的半成品」**。不追求完整 —— 现成脚手架 + 国产模型 API + 阿里云 2核2G，前端能出结果就行。

**第 13 天起同步开卖**。首单定价 199–999 元一次性，或 99–299 元/月。**先收钱，再交付。**

**获客动作清单**（替代 SEO / Reddit / PH / HN）：

- **微信行业群 / 本地同行圈**：直接发「我做了个 X，能帮你省 Y」，带真实截图
- **小红书**：搜「为了 A，我开发了一个 B」这种句式发帖（V2EX 用户的实操经验）
- **V2EX / 掘金**：面向开发者，不直接卖，但能拿到转介绍和第一个用户
- **知乎 / 公众号**：写长文复盘，吸引行业里的从业者
- **猪八戒 / 程序员客栈**：不是终点，是**练手和补充现金流**的渠道。平台在售的 Python 自动化脚本服务明码标价：基础版 ¥68（单一功能、1 天交付）、标准版 ¥168（多功能组合、3 次修改）、高级版 ¥368（复杂多模块 + 项目文档），另有服务商写明「简单任务当天、常规 2–3 天、复杂项目 7 天内」。**这组价格告诉你一件事：客户愿意为一个自动化脚本付 68–368 元——这就是「小微 B 端重复劳动」的定价带。**
- **最有效的一个**：你前同事的同事。**65% 的国内 OPC 订单来自老客户或熟人圈层转介绍**——这是最高杠杆的渠道

> **第 30 天检查点：付费客户 ≥ 8 个。** 如果 = 0 → **换行业，不是换功能**。

### 第 31–60 天：覆盖格式变体 = 建护城河（同时是提转化的开关）

- 把每个新客户的私有格式**抽象成通用配置**。这是外包转产品的分界线：**先从真实交付中识别重复任务，再验证标准化边界**。
- BSC 的教训：覆盖全部格式后，「用户订阅概率大幅上升」。**你的转化率会在这一步跳升。**
- 交付物：一份「我支持哪些格式」的清单 —— 这就是最好的销售素材。
- 开始定价分层（照抄 dashp）：
  - **标准版**：承诺 12 个月，¥199–399/月（可预测收入）
  - **灵活版**：月付，2 倍价，不超过 30% 席（吸收行业季节性——销售员只有半年活跃）

> **第 60 天检查点：≥3 个客户明确说「愿意以后按月付」**——即你已经拥有了一个标准化产品。

### 第 61–90 天：留存 + 转介绍机制

- **做留存**：主动每月帮客户跑一次。托管是留存的核心，也是提客单价的杠杆（月落的做法：按月付费 + 全程托管维护）。
- **做转介绍**：老客户「推荐成功返 1 个月」。dashp 的收入主要来自**老客户升单**，不是新客。
- **做可展示资产**：一个公开页面 + 3 个带数据的案例截图。

> **第 90 天检查点：月经常性收入 ≥ 2000 元 且 月流失 < 8%。** 达标之后，才考虑注册公司、做境内备案、上小程序、投广告。

### 5.1 90 天后的期望值落点

| 结果 | 概率参考 | 说明 |
|---|---|---|
| 0 个付费客户 | 约 40% | 148 问卷：40% 已出产品无付费客户 |
| **1–8 个付费客户，月入 0–3000 元** | **约 35–40%（最可能的落点）** | 411 案例：60% 有收入，但多数停在「注册/激活」层 |
| 月入 3000–10000 元 | 约 15% | 需要已有行业关系 + 1–2 个转介绍 |
| 月入过万 | **< 10%** | 127 人中 3 年做到的有 41 人（32%），但你只有 90 天且无行业存量 |


## 六、风险与止损信号

| 风险 | 触发信号 | 动作 |
|---|---|---|
| **获客失败**（最大风险） | 第 30 天 0 付费客户 | **换行业，不换功能**。重新访谈 15 人 |
| 现金流断裂 | 每月 AI 支出 > 500 元但收入为 0 | 立即砍到 1–2 款工具；API 换国产低价模型 |
| 做成外包、无法产品化 | 第 60 天还在为每个客户写新代码 | 强制停止新定制，把重复部分抽象。否则永远没有产品 |
| 合规卡住 | 备案 / 支付跑不通 | 转个体户 + 微信支付；AI 功能改「签约客户制」规避登记 |
| 平台吸收 | 微信 / 钉钉 / 大厂上线同类 | 提前把护城河放在「格式变体 + 行业 know-how」，不放算法 |
| 克隆竞争 | 出现同类低价复制者 | 转向「托管 + 服务」而非纯软件；服务不可克隆 |
| 客户流失 | 月流失 > 8% | 停掉新增功能，做用户回访；流失 > 15% 直接考虑转型 |
| 彻底无解 | 连续 3 个月收入 0 且无线索 | **止损**。把代码当练手，回职场 |

### 一条容易被忽略的风险：你的时间比 5000 元贵

- 127 人追踪的退出者第 4 个坑是「不舍得外包」。但正确解法不是「什么都自己干」，而是**只把记账报税外包（几百块）**，自己的时间全部投到「获客 + 交付」——这正是复盘里说的：「聪明的玩家花几百块把记账、报税、设计外包，自己只专注获客 + 交付」。
- **不要辞职。** 36 氪调研里「已经全职投入的占 95%，尚未抵达可持续全职经营的有 75%」，「准备直接全职创业的比例为 0」。副业形态的止损成本天然低，这是你最大的隐藏优势，一定要用好。

## 七、该做 / 不该做清单

**该做**

1. 第 0 天办个体工商户（200 元）
2. 选 1 个行业，访谈 15–20 人，**数清格式变体（< 8 种就换）**
3. 第 8 天开始收费，第一单可以只有 199 元
4. 每周 1 次行业社群输出（小红书 / 知乎 / V2EX），持续 90 天
5. 找 5–10 个朋友当「转介绍引擎」
6. 记账报税外包（约 1500 元/年）
7. 每月只看三个数字：**收入 / 留存 / 线索数**

**不该做**

1. 投任何付费广告
2. 先做完整产品再上线（6 个月不上线 = 死）
3. 订阅超过 3 款 AI 工具
4. 做通用简历 / 通用抠图 / 通用 AI 聊天
5. 追热点做节日型产品（春节小程序 392 用户只换来约 120 元）
6. 提前注册公司、买证书、搭大厂级架构 —— 这些都等 8 个客户之后
7. 裸辞

## 八、如果要我只挑一个

**选 #2：垂直行业单据 / 报告的结构化与核对。** 理由：

1. 它天然带「格式变体」护城河——这正是 BSC 被验证过的成功机制（支持更多银行 → 订阅概率大幅上升）
2. 它是闭门 B 端，可规避算法备案 + 大模型登记的 2–8 个月工期——这是 5000 元预算下最值钱的一条
3. 它的客户决策人明确（不是 C 端海量用户），符合「决策人明确且可触达」
4. 它的付费来自甲方的采购预算，与上一份报告「钱从哪个口袋出，决定排名」的结论完全一致
5. 失败成本可控：5000 元 + 30 天，止损也只损失几千块

> **但真正决定成败的不是品类，是你在第 8 天能不能收下第一笔钱。**
> 127 人追踪里「第一天收费」是幸存者共性，86 个退出者里「追求完美产品」是第三大死因。
> 品类决定你能不能活 3 年；第 8 天的第一笔钱决定你能不能开始。
